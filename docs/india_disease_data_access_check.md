## Access instructions and verified links

- **ICAR-IIRR:** Start at the official database description linked above. It presents a “For Link, Click Here” action, but the accessible page did not expose its destination or any file/API endpoint. The official [Institute Portals–Databases directory](https://icar-iirr.org/index.php?Itemid=47&id=39&lang=en&option=com_content&view=article) lists a POS Data Portal without a working public access instruction or format description. No exact download steps can be responsibly supplied. Contact ICAR-IIRR using the published `iirricar@gmail.com` / `040-24591241` details on the database page and ask for the POS disease records, field dictionary, date/geographic resolution, file format, and reuse licence.
- **Bhuvan:** The verified public access route is the [surveillance map/filter page](https://bhuvan-app1.nrsc.gov.in/pest/pest.php). It offers interactive filters, but no documented export action or dataset endpoint was verified. The visible “upload” link is for submitting data and is not a historical download route. Do not scrape or bulk-download records under the general Bhuvan terms without written authorization. Ask NRSC/Bhuvan through its [official contact page](https://bhuvan.nrsc.gov.in/home/index.php) for an authorized historical export/API, format, field definitions, and reuse terms.

## Recommendation for CropAI

Neither source is currently a verified, legally cleared historical record dataset for CropAI weather validation. ICAR-IIRR is the more directly relevant lead for rice and district-scale multi-decade summaries, but its record access and licence remain unverified. Bhuvan's interface and handbook suggest geolocated, dated report records, but a documented export/API and reuse permission are absent; its published terms specifically restrict bulk extraction and reuse without prior written authorization. The next step is a data-access request to each custodian asking for a sample/export, schema, date and location precision, severity definitions, coverage/completeness, and written reuse permission. Only after receipt should weather matching be assessed against actual record resolution. Do not use page descriptions or map filters as outcome rows.
